CampusEats - Database Entity-Relationship Architecture

UIU Smart Canteen Management System | Course: CSE DBMS Lab

Database Engine: MySQL 8.0 (Railway Cloud)
Total Tables: 7 Normalized Tables
Seeded Dishes: 139+ Authentic UIU Items
Active Canteens: Khan's Kitchen, Olympia Palace, Cafe Neptune
🏪 canteens
Parent Entity
ColumnTypeDescription
id PKINT AUTO_INCUnique canteen identifier
nameVARCHAR(100)Canteen name (e.g. Khan's Kitchen)
locationVARCHAR(255)Physical UIU campus venue
is_openTINYINT(1)Live kitchen operating status
created_atDATETIMERecord timestamp
👥 users
RBAC Entity
ColumnTypeDescription
id PKINT AUTO_INCUnique user account ID
nameVARCHAR(100)Student or staff full name
emailVARCHAR(150)Unique UIU campus email
password_hashVARCHAR(255)Bcrypt 10-salt encrypted hash
roleENUM(...)super_admin, local_admin, kitchen_staff, user
canteen_id FKINT (NULL)Assigned canteen for admin/staff
daily_budget_limitDECIMAL(10,2)Student spending guardrail
loyalty_pointsINTAccumulated reward points
penalty_flagsINTNo-show count (Blocks at 3)
is_blockedTINYINT(1)Suspension status flag
🍔 menu_items
Catalog Entity
ColumnTypeDescription
id PKINT AUTO_INCDish identification number
canteen_id FKINTOriginating cafeteria
nameVARCHAR(150)Dish title
descriptionTEXTDish details & ingredients
priceDECIMAL(10,2)Item unit price in BDT
image_urlVARCHAR(500)Food preview banner link
est_prep_time_minsINTKitchen preparation latency
is_availableTINYINT(1)Live real-time in-stock flag
was_available_before_closeTINYINT(1)Kitchen reopening restore cache
📦 orders
Transaction Entity
ColumnTypeDescription
id PKINT AUTO_INCPre-order voucher token
user_id FKINTOrdering student customer
canteen_id FKINTFulfilling canteen counter
total_amountDECIMAL(10,2)Final payable amount
points_redeemedINTDiscount points deducted
points_earnedINTLoyalty points rewarded
statusENUM(...)pending, accepted, preparing, ready, picked_up, cancelled...
requested_pickup_timeDATETIMETarget student pickup window
📋 order_items
Line-Item Entity
ColumnTypeDescription
id PKINT AUTO_INCUnique line-item sequence
order_id FKINTParent order reference
menu_item_id FKINTOrdered dish item
quantityINTNumber of portions
price_at_timeDECIMAL(10,2)Historical price freeze
⭐ reviews
Feedback Entity
ColumnTypeDescription
id PKINT AUTO_INCReview entry record
user_id FKINTReviewing student author
menu_item_id FKINTEvaluated menu dish
ratingINT (1-5)Star rating score
commentTEXTStudent feedback critique
created_atDATETIMEReview submission timestamp
🔔 notifications
Alerts Entity
ColumnTypeDescription
id PKINT AUTO_INCNotification ID
user_id FKINTTarget recipient student
titleVARCHAR(150)Notification banner summary
messageTEXTDetailed status update
is_readTINYINT(1)Read acknowledgment flag
created_atDATETIMETimestamp dispatched

Foreign Key Relationships & Integrity Constraints

  • canteens.id (1) ➜ menu_items.canteen_id (N) (ON DELETE CASCADE)
  • canteens.id (1) ➜ users.canteen_id (N) (ON DELETE SET NULL)
  • users.id (1) ➜ orders.user_id (N) (ON DELETE RESTRICT)
  • canteens.id (1) ➜ orders.canteen_id (N) (ON DELETE RESTRICT)
  • orders.id (1) ➜ order_items.order_id (N) (ON DELETE CASCADE)
  • menu_items.id (1) ➜ order_items.menu_item_id (N) (ON DELETE RESTRICT)
  • users.id (1) ➜ reviews.user_id (N) (ON DELETE CASCADE)
  • menu_items.id (1) ➜ reviews.menu_item_id (N) (ON DELETE CASCADE)
  • users.id (1) ➜ notifications.user_id (N) (ON DELETE CASCADE)
